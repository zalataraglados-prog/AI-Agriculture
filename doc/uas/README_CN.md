# 03 号学术支持信

这封信用于请张教授支持厦门大学马来西亚分校 PalmAI Agri Nexus 团队申请开展有监督的无人机试验。目前正文已整理，签署人暂写为 Professor Zhang（张教授），等待老师核实内容并决定是否签署。

## 信中说明的研究内容

拟通过试验检查影像模糊、树冠遮挡和拍摄覆盖对油棕图像可用性的影响，并检查影像及现场记录能否整理、传入项目的数据分析流程。计划产出影像质量评估、在获准范围内整理的数据集，以及记录结果和局限的简短报告。

信中建议首次试验采用白天、单机、受控场地、飞手目视范围内操作，落地后再做 AI 处理。这是提交审阅的建议范围；飞机配置、人员、场地、日期和操作限制仍需确认。若实际计划涉及自研飞控、自主功能或额外载荷，应如实说明并相应修改。

仓库现有的图像分类和数据接收模块可作为研究背景，但它们不能证明油棕模型效果、飞机适航性或飞控安全性。信中没有写入未经实测的性能数字，也没有声称试飞已经完成。

## 交给老师前需要核实

1. 正式出具前，请张教授核对完整姓名、实际职务、学院或部门及校内邮箱；电话按需要填写。老师需核实相关学生身份，并确认自己认可正文中的学术支持意见。
2. 让负责试验的同学核对上述建议范围与真实方案是否一致。具体飞机、场地和操作参数由相应申请材料说明，不能以这封支持信代替。
3. 如需使用学校或学院信笺，先确认使用权限。签名和签署日期由老师本人完成，不能提前填成已签署状态。

本信只表达学术支持，不指定老师担任运营者或 Accountable Manager，也不代表学校承诺资金、保险、赔偿或机构担保。影像训练、评估、项目记录和公开展示须分别符合实际取得的授权。学术支持不代替飞行许可，航空审批仍需按 [CAAM 的无人机申请要求](https://www.caam.gov.my/public/unmanned-aircraft-system-uas/)办理。
