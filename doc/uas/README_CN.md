# 03 号学术支持信

- [Word 版](03_Faculty_Academic_Support_Letter.docx)
- [在线阅读](03_Faculty_Academic_Support_Letter.md)

这是交给老师审阅、修改和签字的英文草稿。姓名、职务、邮箱和日期均留待填写。

信中说明了油棕影像采集的研究目的，并建议先做小范围、有监督的试验。请老师核对学生身份和研究内容；负责试验的同学需确认信中的描述与实际方案一致。飞机、场地和操作细节由对应申请材料说明。

本信仅作学术支持，不代表飞行许可，也不承诺学校提供资金、保险或赔偿。正式使用前由老师本人确认并签署；使用学校或学院信笺需先取得相应授权。
